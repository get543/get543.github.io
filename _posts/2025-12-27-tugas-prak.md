####  Ketentuan Project

1. Dikerjakan **individu atau kelompok (maks. 3 orang)**.
    
2. Mengimplementasikan materi pembelajaran (HTML, CSS, JavaScript, ReactJS atau PHP).
    
3. Membuat aplikasi berbasis web dengan fitur minimal **CRUD** dan terhubung ke **database** atau **local storage**.
    
4. Boleh menggunakan framework tambahan (NextJS, Laravel, dan lainnya).
    
5. Repository GitHub harus **public** dan digunakan sebagai portofolio serta penilaian.
    
6. Project harus dijelaskan dalam **Manual Book**.
    
7. Project dianggap **DONE** hanya jika semua file lengkap sesuai ketentuan.

##### INFORMASI UJIAN

_INFO UJIAN GRAFIK KOMPUTER (GK)_ Dikarenakan sudah mendekati akhir dari praktikum Grafik Komputer pada semester PTA 25/26 ini. Maka aku ingin memberikan informasi mengenai Project Ujian untuk praktikum Grafik Komputer.  Project wajib meliputi:

1. Gunakan Asset 3D sendiri tidak diperbolehkan untuk mengambil aset dari internet kecuali animasi boleh menggunakan Mixamo.com
2. Menggunakan Rigidbody untuk pergerakan.
3. Menggunakan Collider.
4. Menggunakan Input System.
5. Menggunakan Scene Manager yang berarti harus memiliki lebih dari 1 Scene.

Folder Project dijadikan format .zip dan dikumpulkan pada Google Drive masing-masing.  Isi dari Google Drive:

1. .zip dari Project.
2. Manual Book.

 NOTED:

- Project Dapat dibuat dengan 1 orang atau berkelompok (maks 4 orang per kelompok).
- Tema Project tidak boleh sama dengan orang lain atau kelompok lain.
- Project Mengimplementasikan Semua Yang Dirancang!.
- Akan dilakukan Wawancara, pastikan setiap anggota paham project-nya.
